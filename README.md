# ระบบจองคิวโรงพยาบาลราชเวช เชียงใหม่ (เวอร์ชันใช้จริง)

**Next.js (App Router)**  frontend React + API routes · ข้อมูลเก็บ **MySQL/MariaDB** (โหมดหลัก, toggle ด้วย env `STORAGE`) หรือไฟล์ `data/app-data.json` (โหมด dev) · รายละเอียดติดตั้งดู [DEPLOY.md](DEPLOY.md)

## รัน (dev)

```bash
npm install
npm run dev          # → http://localhost:3000 (หรือตั้ง PORT เช่น PORT=8124)
```

ครั้งแรกจะสร้างข้อมูลเริ่มต้นให้: ผู้ใช้ `admin / admin` (เปลี่ยนทันทีด้วย `npm run setpass -- admin <รหัสใหม่>`) + บริการตัวอย่าง 5 แผนก (แก้ได้จากหน้าเว็บหลังบ้าน)

## รัน (production)

```bash
npm run build
PORT=8124 npm start   # หรือ docker compose up -d
```

## โครงสร้าง

| ส่วน | ไฟล์ |
|---|---|
| หน้าเว็บ (React) — หน้าแรก / วิซาร์ดจอง / ผลจอง / ล็อกอิน / หลังบ้าน | `app/page.js` `app/booking/` `app/success/` `app/login/` `app/admin/` |
| API routes (auth/คิว/ตัวแทน/รายงาน/ส่งออก) | `app/api/**/route.js` |
| Logic กลาง (JWT, ความจุ, ตรวจไฟล์นำเข้า, rate limit) | `lib/core.js` |
| ชั้นข้อมูลสองโหมด (MySQL / ไฟล์ JSON สลับด้วย env) | `lib/store.js` |
| สร้าง/อ่านไฟล์ .xlsx + CSV (ไม่มี dependency เพิ่ม) | `lib/xlsxlite.js` |
| ตัวช่วยฝั่งเบราว์เซอร์ (fetch+token, วันที่) / ค่าตั้งเว็บ | `lib/client.js` `lib/config.js` |
| สคริปต์ดูแลผู้ใช้ | `scripts/setpass.js` `useradd.js` |

หมายเหตุ: ลิงก์เดิม `/*.html` (เช่น `/booking.html` ที่ฝังใน WordPress) ยังเข้าได้ผ่าน rewrite ใน `next.config.js` — ไม่ต้องแก้ลิงก์ที่ไหน

## มีอะไรในตัว

- **3 ช่องทางคิว** ไหลเข้าตารางเดียว: ออนไลน์ (ผู้ป่วยจองเอง) · walk-in (เคาน์เตอร์) · ตัวแทน (กรอกทีละคน วางรายชื่อทั้งชุด หรือ**นำเข้าไฟล์ Excel/CSV**) · **กรองตามตัวแทน** ในตารางคิวได้ (ใช้ร่วมกับตัวกรองวันที่/บริการ/สถานะ และออก CSV ตามตัวแทนที่เลือก) · **รายงานอันดับตัวแทน** ครบทุกสถานะ — ตัวแทนไหนนำลูกค้ามากี่คน มาจริง/ไม่มา/ยกเลิก พร้อมอัตรามาจริง %
- **นำเข้าคิวจากไฟล์ Excel/CSV (ตัวแทน)** — ดาวน์โหลดเทมเพลต .xlsx จากหลังบ้าน (มี dropdown บริการ/สิทธิ์ + ชีตอ้างอิงค่าที่กรอกได้) ตัวแทนกรอกต่างวัน/ต่างเวลา/ต่างบริการในไฟล์เดียวได้ แล้วเจ้าหน้าที่อัปโหลดเพื่อดู preview รายแถวก่อน — แถวที่ไม่ผ่าน (เวลาเต็ม/ข้อมูลไม่ครบ/ซ้ำ) ถูกข้ามพร้อมบอกเหตุผล ไม่บล็อกทั้งไฟล์ · รองรับวันที่ ค.ศ./พ.ศ./date ของ Excel, เบอร์โทรที่โดนตัดเลข 0, CSV แบบ windows-874 (Excel ภาษาไทย)
- **ความจุจริงต่อช่วงเวลา** — ตั้งได้รายบริการ นับจากคิวจริง ยกเลิกแล้วที่นั่งคืนทันที กันจองชนกันฝั่ง server
- **เลขคิววิ่งรายวันต่อบริการ** (คิวที่ 1, 2, 3…) ไม่ซ้ำในวันเดียวแม้มีการยกเลิก
- **ล็อกอินเจ้าหน้าที่ 3 ระดับ**: `admin` (ทุกอย่าง + จัดการผู้ใช้/บริการ/ค่าตั้ง/ดู audit), `sale` (ฝ่ายขาย — งานคิวพื้นฐาน + รับคิวเป็นชุด/นำเข้าไฟล์ของตัวแทน) และ `cs` (ฝ่ายบริการลูกค้า — งานคิวพื้นฐาน: ดู/จัดการคิว รับ walk-in โทรยืนยัน จัดนัดหมาย) — เพิ่ม/แก้ไข/ลบบัญชีได้จากหลังบ้าน (เมนู "จัดการผู้ใช้" ของ admin) หรือ script `npm run useradd` · ใช้ **JWT (HS256)** เขียนเองด้วย node:crypto: ล็อกอินได้ token เก็บใน localStorage ของเครื่องเจ้าหน้าที่ แนบทุกคำขอผ่าน header `Authorization: Bearer …` (ไม่ใช้ cookie → ต้านทาน CSRF และเรียก API ข้ามโดมเนได้) ตั้ง `AUTH_SECRET` ให้ถาวร + ลด `AUTH_TTL_HOURS` ได้ (ผู้ใช้ role `counter` ของระบบเดิมถูกยกระดับเป็น `cs` อัตโนมัติ)
- **ตารางคิวแบ่งหน้า** 10/20/50/100 แถว/หน้า + กระโดดหน้า — รองรับวันพีคเป็นพันคิว สถิตินับจากชุดเต็มเสมอ
- **ค้นหา** ชื่อ/เบอร์/รหัส ข้ามทุกวัน · **เลื่อนนัด** · **สถานะ** รอยืนยัน/ยืนยัน/ไม่มา/ยกเลิก
- **ส่งออก CSV รายวัน** เปิดใน Excel ภาษาไทยได้ทันที (มี BOM + กัน formula injection)
- **PDPA**: checkbox ยินยอมบังคับก่อนจอง + audit log ทุกการกระทำ (เก็บ 500 รายการล่าสุด)
- **กันสแปม**: จองจากภายนอกจำกัด 10 ครั้ง/15 นาที/IP + ล็อกอินผิดจำกัด 10 ครั้ง/15 นาที/IP
- **เบอร์ต่างประเทศ** รับได้ (+95, +86 ฯลฯ) · **ช่องทางติดต่อ = เบอร์โทร "หรือ" อีเมล อย่างน้อย 1 อย่าง** (ต่างชาติที่ไม่ใส่เบอร์กรอกอีเมลอย่างเดียวได้ — ทุกช่องทาง: หน้าจอง/walk-in/คิวชุด/ไฟล์นำเข้า) · ตัวไหนกรอกต้องถูกฟอร์แมต · ค้นหาด้วยเบอร์หรืออีเมลได้ · มีใน CSV export
- บริการ/รายการย่อย/ราคา/**ความจุ**/ช่วงเวลา/**ระยะเวลาเปิดจองล่วงหน้า (ค่าเริ่มต้น 14 วัน)** แก้ได้หมดจากหลังบ้าน ไม่ต้องแตะโค้ด · ตั้งเวลาได้ 3 ระดับ: **ช่วงเวลากลาง** (ทุกบริการ) · **เวลาเฉพาะของบริการ** (ชุดเดียวทุกวัน) · **เวลารายวัน** — จันทร์ 8:00–10:00 / อังคาร 8:00, 9:00, 10:00 แยกกันได้ทุกวัน วันที่ไม่ตั้งเวลา = ไม่ให้บริการวันนั้น
