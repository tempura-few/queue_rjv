# ระบบจองคิวโรงพยาบาลราชเวช เชียงใหม่ (เวอร์ชันใช้จริง)

Pure Node.js · ข้อมูลเก็บ **MySQL/MariaDB** (โหมดหลัก, toggle ด้วย env `STORAGE`) หรือไฟล์ `data/app-data.json` (โหมด dev) · รายละเอียดติดตั้งดู [DEPLOY.md](DEPLOY.md) · รายละเอียดติดตั้งดู [DEPLOY.md](DEPLOY.md)

## รัน (dev)

```bash
node server.js        # → http://localhost:8124
```

ครั้งแรกจะสร้างข้อมูลเริ่มต้นให้: ผู้ใช้ `admin / admin` (เปลี่ยนทันทีด้วย `scripts/setpass.js`) + บริการตัวอย่าง 5 แผนก (แก้ได้จากหน้าเว็บหลังบ้าน)

## โครงสร้าง

| ส่วน | ไฟล์ |
|---|---|
| Server + API + สิทธิ์ + rate limit + audit | `server.js` |
| ชั้นข้อมูลสองโหมด (MySQL / ไฟล์ JSON สลับด้วย env) | `store.js` |
| หน้าเว็บผู้ป่วย (จอง/ดูผล) | `public/index.html` `booking.html` `success.html` |
| หน้าล็อกอิน + หลังบ้าน | `public/login.html` `admin.html` |
| ตัวช่วยร่วม (fetch, วันที่, หน้าตา) | `public/api.js` `config.js` `styles.css` |
| สคริปต์ดูแลผู้ใช้ | `scripts/setpass.js` `useradd.js` |

## มีอะไรในตัว

- **3 ช่องทางคิว** ไหลเข้าตารางเดียว: ออนไลน์ (ผู้ป่วยจองเอง) · เดินสด (เคาน์เตอร์) · ตัวแทน (กรอกทีละคน หรือวางรายชื่อทั้งชุดจาก Excel/LINE)
- **ความจุจริงต่อช่วงเวลา** — ตั้งได้รายบริการ นับจากคิวจริง ยกเลิกแล้วที่นั่งคืนทันที กันจองชนกันฝั่ง server
- **เลขคิววิ่งรายวันต่อบริการ** (คิวที่ 1, 2, 3…) ไม่ซ้ำในวันเดียวแม้มีการยกเลิก
- **ล็อกอินเจ้าหน้าที่** 2 ระดับ: `admin` (จัดการบริการ/ดู audit) และ `counter` (รับคิว/ค้นหา/เลื่อน/ยกเลิก/ส่งออก)
- **ค้นหา** ชื่อ/เบอร์/รหัส ข้ามทุกวัน · **เลื่อนนัด** · **สถานะ** รอยืนยัน/ยืนยัน/ไม่มา/ยกเลิก
- **ส่งออก CSV รายวัน** เปิดใน Excel ภาษาไทยได้ทันที (มี BOM)
- **PDPA**: checkbox ยินยอมบังคับก่อนจอง + audit log ทุกการกระทำ (เก็บ 500 รายการล่าสุด)
- **กันสแปม**: จองจากภายนอกจำกัด 10 ครั้ง/15 นาที/IP
- **เบอร์ต่างประเทศ** รับได้ (+95, +86 ฯลฯ) รองรับฐานคนไข้ต่างชาติ
- บริการ/รายการย่อย/ราคา/**ความจุ**/ช่วงเวลา (กลาง + เฉพาะรายบริการ) แก้ได้หมดจากหลังบ้าน ไม่ต้องแตะโค้ด

## ขอบเขตที่ตกลงกับลูกค้า (30,000 บาท)

ส่งมอบเวอร์ชันนี้ติดตั้งบนเซิร์ฟเวอร์ของ รพ. · รับประกันแก้บั๊ก 6 เดือน (ปัญหาเครือข่าย/ฮาร์ดแวร์/OS ของ รพ. ไม่รวม) · งานเสริม (SMS / บัญชีตัวแทนเต็มรูปแบบ / LINE / รายงานผู้บริหาร / เพิ่มแผนก) ตามใบเสนอราคา Q-001/2569
