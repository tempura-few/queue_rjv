# วิธีเสียบเข้าเว็บ WordPress ของโรงพยาบาล

มี 3 ทาง เลือกตามความพร้อมของทีมดูแลเว็บ รพ.

---

## ทาง 1 — ปุ่ม/เมนูลิงก์ออกไปหน้าจอง (แนะนำ เริ่มด้วยอันนี้)

ให้ทีม WordPress เพิ่มปุ่ม **"จองคิวออนไลน์"** ในเมนูหลัก/หน้าแรก ชี้ไปที่
`https://queue.rajavejchiangmai.com` (ซับโดเมนที่จะตั้งให้ระบบคิว)

**ทำใน WP ไม่ถึง 10 นาที:** เมนู → Appearance → Menus → Custom Link แล้วติ๊ก
"Open link in a new tab" หรือเปิดหน้าเดียวกันก็ได้

- ✅ ไม่กระทบเว็บ WP เดิมเลย แยกขอบเขตชัด อัปเดตสองระบบไม่พันกัน
- ✅ ความเสี่ยงต่ำสุด ตรงตามสัญญา 30k (ไม่ต้องรับผิดชอบโค้ด WP)
- ➖ ผู้ใช้เปลี่ยนโดเมน แต่กดปุ่มเดียว คนไข้ทั่วไปไม่รู้สึก

## ทาง 2 — ฝังหน้าจองไว้ในหน้า WP (สวยกว่า ดูเป็นเว็บเดียว)

ระบบรองรับ **โหมด embed** แล้ว: เพิ่ม `?embed=1` ท้าย URL จะซ่อนหัว-ท้าย
ออกให้พอดีกับหน้าที่ฝัง ใช้ iframe + shortcode ต่อไปนี้

**ขั้น 1:** วางโค้ดนี้ในไฟล์ `functions.php` ของธีมลูก (child theme) —
หรือใช้ปลั๊กอินอย่าง WPCode แปะเป็น PHP snippet ก็ได้ ไม่ต้องแตะธีมหลัก:

```php
// Shortcode [queue_booking] — ฝังหน้าจองคิวลงหน้า WordPress
function queue_booking_shortcode($atts) {
  $a = shortcode_atts(array(
    'service' => '',      // เช่น service="dental" เปิดมาเลือกทันตกรรมไว้ก่อน
    'height'  => '1650',  // ความสูง iframe ปรับได้
  ), $atts);
  $url = 'https://queue.rajavejchiangmai.com/booking.html?embed=1';
  if ($a['service']) $url .= '&service=' . rawurlencode($a['service']);
  return '<iframe src="' . esc_url($url) . '"
    style="width:100%;height:' . intval($a['height']) . 'px;border:0;"
    loading="lazy" title="จองคิวออนไลน์"></iframe>';
}
add_shortcode('queue_booking', 'queue_booking_shortcode');
```

**ขั้น 2:** สร้างหน้าใน WP ชื่อ "จองคิวออนไลน์" แล้วใส่ในเนื้อหา:

```
[queue_booking]
```

แต่ละแผนกจะฝังเฉพาะบริการตัวเองก็ได้: `[queue_booking service="dental"]`

- ✅ อยู่ในโดเมนเว็บ รพ. ตลอด ดูเป็นเว็บเดียว ลิงก์เมนูสวย
- ✅ การจองไม่ใช้ cookie จึงฝังข้ามโดเมนได้ไม่มีปัญหา (หน้าเจ้าหน้าที่ห้ามฝัง — เข้าตรง queue.…/login.html เท่านั้น)
- ➖ ต้องดูแลธีมลูก/WPCode นิดหน่อย และความสูง iframe บนมือถือให้เผื่อฟอร์มยาว

## ทาง 3 — เขียนปลั๊กอิน WP จริง ๆ คุย API ตรง ๆ (ไม่แนะนำตอนนี้)

ทำได้แต่จะบวม scope: ต้องเขียน PHP, ดูแลความปลอดภัยสองฝั่ง, และทำให้เรา
รับผิดชอบบางส่วนของเว็บ WP ทั้งเว็บ ที่งบ 30k ไม่คุ้ม — เก็บไว้เป็นงานเสริมรอบหน้า
(ตั้งชื่อราคาได้ว่า "ปลั๊กอิน WordPress เชื่อมลึก")

---

## เรื่องที่ต้องถามไอที รพ. ก่อนติดตั้ง (สำคัญ)

1. **เว็บ WP โฮสต์แบบไหน?**
   - VPS/เครื่องเฉพาะที่ล็อกอิน shell ได้ → อาจรันระบบคิวรวมเครื่องเดียวกันได้เลย (แยกพอร์ต + nginx)
   - **Shared hosting (cPanel ทั่วไปที่เว็บไทยใช้) → รัน Node ไม่ได้** ต้องหาเครื่องแยกให้ระบบคิว: เครื่องภายใน รพ. หรือ VPS เล็ก (เช่น AWS Lightsail ~350฿/เดือน โซน Bangkok)
2. **มีซับโดเมนจัดการเองได้ไหม** — ขอ `queue.` ชี้มาที่เครื่องระบบคิว พร้อมออกใบ SSL (Let's Encrypt ฟรี ตาม DEPLOY.md)
3. ใครดูแล DNS/โดเมน — ต้องขอสิทธิ์แก้ record หนึ่งครั้งตอนตั้ง

## สรุปที่แนะนำเป็นแผนเปิดตัว

- **สัปดาห์แรก:** ทาง 1 (ปุ่มลิงก์) — เปิดใช้ได้ทันทีที่ deploy เสร็จ
- **ตามด้วย:** ทาง 2 (ฝังหน้า) ในหน้า "จองคิวออนไลน์" ของเว็บ รพ. — ให้ประสบการณ์เว็บเดียว
