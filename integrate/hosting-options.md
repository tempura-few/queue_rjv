## ช้อย A — VPS เล็กของเราดูแล (แนะนำ)

**AWS Lightsail โซนกรุงเทพฯ ประมาณ 350 ฿/เดือน** (เครื่องเล็กสุดพอสำหรับคิว รพ. หลายเท่า)

- ผู้พัฒนาตั้งเครื่อง + ระบบ + HTTPS ให้ครบใน 1 วัน ไม่ต้องรอใคร
- โซนข้อมูลอยู่ในประเทศไทย — สอดคล้อง PDPA เรื่องข้อมูลคนไข้
- รพ. จ่ายค่าเครื่องกับ AWS ตรง ๆ ด้วยบัตรของ รพ. (โปร่งใส เปลี่ยนผู้ดูแลได้เสมอ)
- เหลือแค่ขอ Z.com เพิ่ม A record: `queue` → IP ของเครื่องนี้

## ช้อย B — VPS ที่ Z.com ค่ายเดิม

ราคาประมาณ 500–900 ฿/เดือน แล้วแต่แพ็กเกจ

- ข้อดี: ผู้ให้บริการเดียวกับเว็บ+อีเมล ไอที รพ. คุ้นเคย จดบิลรวมกัน
- ข้อเสีย: การเข้าเครื่อง/ติดตั้งต้องผ่านขั้นตอนของฝ่าย support ของเขา ผู้พัฒนาเข้าถึงเครื่องได้ช้ากว่า แก้ปัญหาด่วนตอนกลางคืน/วันหยุดได้ลำบากกว่า

## ช้อย C — เครื่องเซิร์ฟเวอร์ภายใน รพ.

ไม่มีค่ารายเดือน ใช้เครื่องที่ รพ. มีอยู่

- ข้อดี: ข้อมูลอยู่ในบ้าน 100% ไม่มีค่าใช้จ่ายรายเดือน
- ข้อเสีย: ต้องมีไอทีประจำเปิดพอร์ต 80/443 + ทำ HTTPS + ดูแลเครื่องไม่ให้ดับ — เครื่องดับ/เน็ตหลุดเมื่อไหร่ **คนไข้จองคิวไม่ได้ทันที** และผู้พัฒนาแก้ปัญหาจากภายนอกได้เฉพาะกรณีที่มีการเปิดทางให้
- เหมาะเมื่อ รพ. มีทีมไอทีประจำจริงจัง

| ค่าใช้จ่าย/เดือน | ~350 ฿ | ~500–900 ฿ | 0 ฿ |
